# Solana conformance IDLs

These IDLs are generated by Anchor from the local conformance programs. The `address` field in each IDL is the public scaffold program identity. It is not evidence of a network deployment or authorization to transact.

From the repository root, run:

```bash
node contracts/solana/scripts/build-conformance-artifacts.mjs
```

The script builds both local SBF programs first, with the `conformance` feature enabled on the core program. This produces the ignored `target/deploy` binaries required by the LiteSVM execution tests. It then uses `anchor idl build` with the same core feature. IDL compilation limits Cargo to `--lib` because integration tests load those SBF binaries from the workspace target directory. Publication checks the execution instruction, required accounts and types, and the venue identity before copying either generated IDL here.
