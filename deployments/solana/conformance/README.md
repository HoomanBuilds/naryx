# Solana conformance IDLs

These IDLs are generated by Anchor from the local conformance programs. The `address` field in each IDL is the public scaffold program identity. It is not evidence of a network deployment or authorization to transact.

From the repository root, run:

```bash
node contracts/solana/scripts/publish-conformance-idls.mjs
```

The script uses `anchor idl build` with the `conformance` feature for the core program. It limits Cargo to `--lib` because integration tests load local SBF artifacts that may not exist in a clean checkout. Publication checks the execution instruction, required accounts and types, and the venue identity before copying either generated IDL here.
