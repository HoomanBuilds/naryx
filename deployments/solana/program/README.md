# Solana program ABI

`idl/naryx_core.json` is generated from the normal, non-conformance `naryx_core` program surface by `contracts/solana/scripts/build-program-artifacts.mjs`.

This is an ABI-only artifact. Its declared address is the scaffold identity from source. It is not a deployment record, does not claim that a program is deployed on any network, and does not authorize deployment or writes.
